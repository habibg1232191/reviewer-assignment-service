# Тестовое задание: Сервис назначения ревьюеров для Pull Request’ов (Осенняя волна 2025)

## Описание проекта

Это микросервис для автоматического назначения ревьюеров на Pull Request’ы (PR) внутри команды, управления командами и участниками.  
Сервис полностью RESTful и взаимодействует через HTTP API (OpenAPI 3.0 спецификация находится в файле `openapi.yaml`).

Основные возможности:

- Создание команд и пользователей.
- Автоматическое назначение до 2 ревьюверов на новый PR.
- Переназначение ревьюверов на активных участников команды.
- Получение списка PR, назначенных пользователю.
- Идемпотентное слияние PR (`MERGED`) — повторный merge не приводит к ошибке.
- После `MERGED` состав ревьюверов менять нельзя.

## Стек технологий

- Язык: Go 1.21
- Фреймворк HTTP: Gorilla Mux
- База данных: PostgreSQL 15
- Контейнеризация: Docker + Docker Compose
- Миграции: SQL файлы в директории `migrations`
- Логирование: slog
